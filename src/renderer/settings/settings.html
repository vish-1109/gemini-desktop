General

Window behavior, startup options, and notifications.

Launch at login Starts Gemini quietly in your system tray when you log in (~/.config/autostart).
Close window hides to tray Keep Gemini running in the system tray when closing the window.
Start minimized in tray Launch hidden in the tray on normal startups unless toggled open.
Notify when response completes Send a desktop notification when Gemini finishes a reply while the window is hidden or unfocused.
Window frame style Choose sleek Material titlebar or native Linux system titlebar (restart required).
Default page zoom Adjust text and layout scaling (or press Ctrl+ / Ctrl- anytime).

Privacy & Permissions

Control hardware permissions, Google session state, updates, and local diagnostic logs. No Google telemetry is sent.

Google Account Switch between signed-in Google accounts or clear session cookies.
Microphone access Allow Gemini Live and voice prompts to use your microphone.
Camera access Allow Gemini to capture camera input when requested.
Location access Allow Gemini to query approximate browser location when requested.
Web notifications & clipboard Allow Gemini pages to request desktop notifications and clipboard read access.
Check GitHub Releases automatically Checks public GitHub Releases on launch with zero user identifiers.
Sanitized diagnostic logs View recent local logs with home paths, emails, and tokens automatically redacted.
